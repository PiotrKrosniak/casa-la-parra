# Casa La Parra — interactive estate plan

Browser-viewable 3D concept model of the property in Tous, Valencia.

Published with GitHub Pages. Open index.html through a web server, e.g. `python3 -m http.server 8000`.

The GLB contains visible project geometry only. The editable Blender source and architectural reference documents remain in the local project. Dimensions, building details and terrain elevations are provisional.

Viewer: Google model-viewer 4.1.0, loaded from unpkg. Model materials are simplified for browser display.
